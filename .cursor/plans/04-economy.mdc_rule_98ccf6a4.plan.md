# План: `.cursor/rules/04-economy.mdc`

## Назначение

Фиксировать поведение агента в духе **экономии**: меньше лишнего текста и токенов, меньше избыточных чтений файлов, ответы соразмерны задаче. Это дополняет пользовательские предпочтения (лаконичность, без наполнителя) на уровне репозитория.

## Frontmatter

- **`description`**: кратко — экономия контекста и ответов агента в этом репо.
- **`alwaysApply: true`** — иначе правило почти не сработает.
- **`globs`**: не указывать (глобальное правило).

## Содержание (сжато, ~35–50 строк)

1. **Ответы** — по делу; не раздувать простые правки; избегать повторов того, что уже в [01-core.mdc](.cursor/rules/01-core.mdc) / [.cursorrules](.cursorrules) (команды, назначение проекта), если это не нужно для текущего шага.
2. **Инструменты и код** — не читать большие файлы целиком без нужды; для правок — релевантные фрагменты; не вставлять в чат огромные дампы кода «для примера».
3. **Цитирование** — при ссылке на код предпочитать формат Cursor `startLine:endLine:path` (как в правилах пользователя), а не копипаст целых файлов.
4. **План и объяснения** — сложное — структурировать кратко; тривиальное — без лишних секций и «engagement» в конце.
5. **Конфликт с точностью** — экономия не отменяет корректность: если нужен контекст для безопасного патча — читать/искать.

Язык правила: **русский**, в одном стиле с [01-core.mdc](.cursor/rules/01-core.mdc) и [share-terminal-output.mdc](.cursor/rules/share-terminal-output.mdc).
